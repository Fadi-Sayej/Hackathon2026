# SmartShelf AI

واجهة Hackathon لبناء طبقة قرار ذكية فوق بيانات متجر/كازية من أجل:

- اقتراح طلبات شراء ذكية.
- تحليل المخزون والمخاطر.
- تنظيم الرفوف بصرياً عبر `Planogram`.
- شرح التوصيات بصيغة `Mock AI`.
