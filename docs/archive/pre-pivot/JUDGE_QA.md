# SmartShelf AI — Judge Q&A

Honest, confident answers to the questions judges are most likely to ask.

---

## "Is this real AI?"

**Honest answer:** It depends on which layer you mean.

The analytics engine — inventory risk scoring, reorder recommendations, planogram placement — is deterministic retail logic running in the browser. It is not a neural network, but it is not fake either: it calculates from real data using real formulas (rolling velocity, days-until-stockout, margin weighting).

The explanation text on each recommendation card is generated by a rule-based engine by default, so the demo stays stable without any backend call.

The Gemini-2.0-flash integration is built and working. It's behind a FastAPI proxy (`src/api/llm_proxy.py`). Set `VITE_LLM_PROXY_URL` and run `uvicorn src.api.llm_proxy:app --port 8000` and every explanation comes from Gemini instead.

**What to say:** "The recommendation engine is deterministic retail analytics — real calculations on real data. The explanation layer uses Gemini through a backend proxy we've built. We run rule-based explanations during the demo so there's no live API dependency."

## "Where does the data come from?"

**Honest answer:** Two sources.

1. **Internal inventory:** A real POS export from YomYom, an Israeli convenience store chain. 7,674 products with Hebrew names, real purchase and selling prices, and real department structure. This is the dataset powering every metric in the app.

2. **Competitor prices:** A mock neighborhood snapshot modeled on Israel's food price transparency law (Hok HaMazon). Every major retail chain is required by law to publish hourly XML price feeds. The demo uses a realistic synthetic snapshot of four nearby chains. The pipeline to pull live data from the actual portal is built.

Kaggle data: 61,155 SKUs from Shufersal, Rami Levy, and Dor Alon have been imported into the pipeline for barcode matching — the frontend connector for that is one script run away.

**What to say:** "Internal inventory is a real POS export from YomYom — 7,674 products, Hebrew names, real prices. Competitor data uses Israel's mandatory price transparency format — we've modeled a realistic neighborhood snapshot. The live data pipeline is built."

## "How accurate is it?"

**Honest answer:** The analytics are as accurate as the data.

- Stockout risk: calculated from current stock ÷ rolling 7-day sales velocity. Deterministic.
- Reorder quantity: based on lead time and safety stock formula. Deterministic.
- Planogram scoring: weighted by margin, velocity, and capacity. Deterministic.

In the demo dataset, sales history is estimated (the YomYom POS export contains stock and prices, not a rolling sales history). A real POS import with time-series data would make all the analytics exact.

AI explanation accuracy depends on which provider is running. Rule-based is consistent. Gemini adds natural-language quality but is not doing additional reasoning beyond the metrics passed to it.

**What to say:** "The analytics are deterministic — same input always produces the same output. In a real deployment, accuracy improves with longer sales history. The demo uses a representative dataset to show the workflow."

## "What happens if APIs fail?"

**Honest answer:** Nothing breaks. Every live signal has a static fallback, and the fallback is always loaded first.

- Market context (weather, holidays, news): if the live APIs fail or timeout, `fallbackMarketContext.js` is used. The panel still shows data; it just labels itself "static fallback."
- Competitor prices: the demo uses local mock data — there is no live API call during the demo.
- AI explanations: if Gemini proxy is unreachable, the code falls back to `mockExplanationProvider`. The UI never shows an error.
- Data load: if no POS data is loaded, the app shows empty states with helpful messages — it never crashes.

**What to say:** "The app is designed to be offline-safe. Every live signal has a labeled fallback. You can run it on a laptop with no internet and it still shows the full workflow."

## "Why would a store owner pay?"

**Honest answer:** Time and money.

- A convenience store owner spends 30–60 minutes per day on manual ordering decisions. SmartShelf AI reduces that to under 5 minutes.
- Stockouts cost revenue — a product that is out of stock on a busy Friday evening is a lost sale.
- Overstock ties up working capital and creates expiry risk — expired goods are pure loss.
- Better shelf allocation means the highest-margin products get the best spots, increasing revenue per square meter.

Pricing hypothesis: free 30-day pilot, then ₪299/month per store. That is less than the value of one prevented stockout per week.

**What to say:** "Time saved, stockouts prevented, waste reduced. A 30-minute daily ordering decision becomes a 5-minute approval workflow. One prevented stockout per week more than covers the subscription."

## "What happens after the hackathon?"

**Honest answer:** Three concrete next steps.

1. **Three-store pilot (30 days):** Run with three YomYom or similar stores. Measure ordering time before/after, stockout rate before/after, and waste rate before/after.

2. **Supabase backend:** Move localStorage to a proper store-accounts database. This enables order history, multi-device access, and multi-store comparison.

3. **Real POS connector:** Wire the Comax API (or Priority ERP) so the owner never exports a CSV — the data flows in automatically.

Longer term: multi-store chain analytics, supplier API integration, and the RAG-based explanation layer (corpus structure is already built).

**What to say:** "Three-store pilot next, then Supabase persistence, then live POS integration. The architecture is designed so each step drops in without rewriting the core analytics."

## "What's the market size?"

**Honest answer:** We have not done a formal TAM analysis. What we can say:

- Israel has approximately 4,000–5,000 gas station convenience stores and 8,000–10,000 small grocery and mini-market locations.
- At ₪299/month per store, 1,000 stores = ₪300K MRR.
- The product is also applicable to any small-format retailer in any country with price transparency laws — which includes most of the EU.

**What to say:** "The addressable market in Israel is thousands of small-format stores. The product generalizes to any country with mandatory price transparency — which includes much of Europe."
