# The sign-in page — screens for approval

The repository owner asked on 2026-10-03 to change the sign-in page's layout, wording, sign-in
options and error message ("all"). The screens below were taken from the real components in
English, Hebrew and Arabic, at desktop and phone size.

## What changed

| | Before | After |
|---|---|---|
| **Layout** | The app's frame with its nav taken out: an empty dark sidebar, and a card floating on an empty page | A welcome screen. The brand side carries what SmartShelf does, in one headline and three points, with the language switch. The sign-in card sits beside it, and on a phone below it |
| **Wording** | "To open SmartShelf, sign in with your Google account or your email." | "Use your Google account, or your email and password." A line under the card: "Only accounts the team has added can open SmartShelf." |
| **Options** | Google, or an email link every time on a new device | Google, **or email and password** (asked for on 2026-10-03: "on another device I need to type my email and sign in, not get a link again"). "Forgot your password, or never set one?" emails a link to set one, which is also how the first password is set. "Email me a sign-in link instead" stays as a fallback |
| **Errors** | One sentence for every failure: "Sign-in didn't work. Try again." | The reason Firebase gives, in words (below). Anything else keeps the old sentence |

The roles are unchanged (ADR-029). A password belongs to the same account as Google or the email link, so it keeps its role.

**One console step for the repository owner:** in Firebase, Authentication → Sign-in method → Email/Password must be **enabled** (the first switch, not only "Email link"). Until then, the page says password sign-in is not switched on.

## The error messages

| When | It says (English) |
|---|---|
| The address is not one sign-in accepts (preview or branch addresses) | "Sign-in only works at hackathon2026-fadi19.vercel.app.", with a link. The address is the store's own `site.address` in `configs/store.yaml`, so each store's copy names its own. Not Vercel's production domain: for this project that is `hackathon2026-ten-theta.vercel.app`, which Firebase does not accept either |
| The browser blocked Google's window | "Your browser blocked Google's window. Allow pop-ups for this site, or use the email link." |
| An old or used email link | "This sign-in link has expired or was already used. Send yourself a new one." |
| A mistyped address | "That doesn't look like an email address." |
| No connection | "There's no internet connection. Try again when you're online." |
| Too many tries | "Too many tries. Wait a minute, then try again." |
| A wrong email or password | "The email or password is wrong." Firebase does not say which, so the page does not either |
| No password typed | "Type your password, or use one of the options below." |
| Password sign-in not switched on in Firebase | "Password sign-in isn't switched on yet. Use Google or the email link." |
| Anything else | "Sign-in didn't work. Try again." |
